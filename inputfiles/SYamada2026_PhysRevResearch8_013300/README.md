# WSe2-graphene heterobilayer, Pulse irradiation, TDDFT

- Publication information
    - [1] S. Yamada, A. Hashmi and T. Otobe, "Ultrafast spin injection in graphene via dynamical carrier filtering at transition metal dichalcogenide interfaces", Phys. Rev. Research 8, 013300 (2026). DOI: 10.1103/xslx-wnb6
    
- Version of SALMON
    - SALMON v.2.2.2.

- System
    - WSe2-graphene heterobilayer.
    
- Purpose
    - Spin transfer dynamics in the heterobilayer. Fig. 3 in Ref [1].

- Method
    - TDDFT.

- Other information
    - Details of files: input_hetero.dat = WSe2-graphene heterobilayer. input_graphene.dat = isolated graphene. input_wse2.dat = isolated WSe_2. 
    - Calculation time ~ 37 hours for 40 fs (Fugaku computer, 512 nodes).
    - Links for the pseudopotential file:
    - https://www.openmx-square.org/vps_pao2019/W/W_CA19.vps
    - https://www.openmx-square.org/vps_pao2019/Se/Se_CA19.vps
    - https://www.openmx-square.org/vps_pao2019/C/C_CA19.vps
